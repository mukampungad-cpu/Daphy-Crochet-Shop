## About the Project

Daphy Crochet Shop was created to give a handmade crochet business a professional online presence.

The website uses a warm cream, beige and brown colour palette to reflect the handmade nature of the brand. It presents products with photographs and prices and provides information to help customers understand the business and its ordering process.

The main goal is to create a simple, welcoming and user-friendly shopping experience.

## Project Objectives

- Create a professional website for Daphy Crochet Shop.
- Showcase handmade crochet products online.
- Organise products into categories.
- Allow customers to view product photographs and prices.
- Make it easier for customers to review their selected products.
- Provide business, customer and contact information.
- Make the website usable on different screen sizes.

## Website Features

### 1. Home Page

Introduces Daphy Crochet Shop and welcomes visitors to the website.

### 2. Shop Page

Displays crochet products with their photographs, names and prices.

### 3. Product Categories

Allows customers to filter products and view items belonging to a selected category.

### 4. Shopping Cart

Allows customers to add products to their cart, review selected items, remove unwanted products and see the total price.

### 5. About Us Page

Introduces the business and shares its story and values.

### 6. Customer Information Page

Provides useful information to help customers understand the shopping and ordering process.

### 7. Contact Page

Provides ways for customers to contact Daphy Crochet Shop.

### 8. Responsive Design

Designed to provide a convenient experience across desktop, tablet and mobile screen sizes.

## Project Structure

The project is organised into folders to keep the application code, pages, reusable components, data and images separate.

- Daphy-Crochet-Shop/ │ ├── public/ │   └── images/ │       └── Product images and other public images │ ├── src/ │   │ │   ├── assets/ │   │   └── Images and other imported assets │   │ │   ├── components/ │   │   └── Navbar.jsx │   │ │   ├── data/ │   │   └── Product data and related data files │   │ │   ├── pages/ │   │   ├── Home.jsx │   │   ├── Shop.jsx │   │   ├── About.jsx │   │   ├── Contact.jsx │   │   └── CustomerInformation.jsx │   │ │   ├── App.jsx │   ├── App.css │   ├── index.css │   └── main.jsx │ ├── .gitignore ├── eslint.config.js ├── index.html ├── package.json ├── package-lock.json ├── vite.config.js └── README.md

  **What the folders and files do:**
  - **public/images:** Stores product photographs and other public images used on the website.
  - **src/assets:** Stores assets imported into the React application.
  - **src/components:** Contains reusable interface components, such as the navigation bar.
  - **src/data:** Keeps product information and other application data organised.
  - **src/pages:** Contains the different website pages.
- **App.jsx:** Brings the application pages and navigation together.
- **App.css:** Contains styling for the application.
- **index.css:** Contains general website styles.
- **main.jsx:** Entry point that renders the React application.
- **package.json:** Contains project information, dependencies and scripts.
- **vite.config.js:** Contains Vite configuration.
- **README.md:** Provides information and instructions about the project.



## How the Application Works

The website is built with React. The interface is divided into components and pages to make the code easier to organise and maintain.

React Router is used to navigate between the different pages.

Product information is organised separately from the page layout. Category filtering helps customers find products in the category they want.

The shopping cart allows customers to review their selected products and see the total price before proceeding with the ordering process.

## Getting Started

### Prerequisites

- Node.js
- npm
- Visual Studio Code (recommended)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/mukampungad-cpu/Daphy-Crochet-Shop.git
```

**2. Open the project folder**

```bash
cd Daphy-Crochet-Shop
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the website**

Visit the local address displayed in your terminal, usually:

```text
http://localhost:5173/
```
